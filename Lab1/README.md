## Метод Якоби для собственных чисел и собственных векторов

### Быстрый запуск

Откройте терминал в папке Lab1. Требуется Python 3.10 или новее.

```powershell
python -m pip install .
python -m jacobi_lab
python -m jacobi_lab examples/matrix.json --max-sweeps 100
python -m jacobi_lab examples/matrix.json --epsilon 1e-20
python -m unittest discover -s tests -v
```

После установки доступна также команда `jacobi-lab`. При отсутствии пути
используется матрица 5×5. Входной файл — JSON-массив строк.
Успешный запуск возвращает код 0, предусмотренная ошибка — код 2 с пояснением.
Неверные аргументы командной строки обрабатывает `argparse`.

### Публичный интерфейс

```python
from jacobi_lab import jacobi_eigh, jacobi_rotation, JacobiError

try:
    result = jacobi_eigh([[2, 1], [1, 2]], max_sweeps=100)
    print(result.eigenvalues)       # [1. 3.]
    print(result.eigenvectors)      # столбцы собственных векторов
except JacobiError as error:
    print(error)

# Один шаг метода (начиная с нулевого индекса)
step = jacobi_rotation(A, 1, 3)   # step.matrix, step.tan, step.cos, step.sin
```

| Аргумент | Значение и контракт |
|---|---|
| `matrix` | Непустой квадратный массив вещественных чисел, точно симметричный после преобразования в float64 |
| `epsilon=None` | Порог остановки. Если задано число — абсолютный порог суммы квадратов всех внедиагональных элементов. `None` (по умолчанию) — относительный порог `‖offdiag(A)‖F < machine_eps·‖A‖F`, одинаково точный для любого масштаба матрицы |
| `max_sweeps=100` | Неотрицательное целое число полных проходов; 0 разрешает только уже достигнутую точность |

Строки, комплексные числа, булевы матрицы, NaN, бесконечности и массивы
произвольных объектов не принимаются. Входной массив не изменяется.

| Поле `JacobiResult` | Значение |
|---|---|
| `eigenvalues` | Собственные числа по возрастанию |
| `eigenvectors` | Ортонормированные векторы: столбец j соответствует числу j |
| `sweeps`, `rotations` | Число полных проходов и отдельных поворотов |
| `scale` | Максимальный модуль элемента исходной матрицы; для нулевой матрицы 1 |
| `offdiag_norm_scaled` | Финальная внедиагональная норма Фробениуса, делённая на scale |
| `history` | Та же норма до итераций и после каждого полного прохода |
| `tolerance_scaled` | Порог, с которым сравнивалась `offdiag_norm_scaled` |

`jacobi_rotation(matrix, p, q)` выполняет один поворот, зануляющий элемент
`(p, q)`, и возвращает `JacobiStep(matrix, tan, cos, sin)`.

Знак собственного вектора выбирается так, чтобы его наибольшая по модулю
компонента была положительной. При кратных собственных числах базис собственного
подпространства не единственен: покомпонентное сравнение векторов с NumPy неверно.
Массивы результата принадлежат вызывающему коду; `frozen` защищает поля структуры
от переназначения, но не делает содержимое NumPy-массивов неизменяемым.

### Алгоритм и точность

1. Проверяем входные данные и копируем матрицу.
2. Масштабируем B = A / scale и начинаем с V = I.
3. Циклически обходим пары p < q. Для ненулевого B[p,q] вычисляем поворот Гивенса.
4. Обновляем только две строки/столбца B и два столбца V, используя старые значения.
5. После прохода заново вычисляем внедиагональную норму. Завершаем, когда
   `offdiag_norm_scaled < sqrt(epsilon) / scale` (явный `epsilon`) или
   `offdiag_norm_scaled < machine_eps · ‖A/scale‖F` (`epsilon=None`).
6. Сортируем собственные пары, возвращаем исходный масштаб, проверяем невязку и ортогональность.

Основное преобразование: **B ← P^TBP**, **V ← VP**.
Для C = (B[q,q] − B[p,p]) / (2B[p,q]) выбирается корень
`t = sign(C) / (|C| + sqrt(C² + 1))`; при C = 0 используется t = 1.
В коде применяется алгебраически эквивалентная масштабированная форма без
деления на очень малый внедиагональный элемент. Затем
`c = 1 / hypot(1, t)`, `s = t*c`.

**Почему по умолчанию не абсолютный порог.** Абсолютный критерий S < ε зависит от масштаба:
для `[[2, 1], [1, 2]]·1e-12` сумма S = 2·10^(-24) меньше ε = 10^(-20) ещё до первого поворота,
и прежняя версия (1.0.0, `epsilon=1e-20` по умолчанию) без ошибки возвращала неверный спектр
`[2e-12, 2e-12]` вместо `[1e-12, 3e-12]`. Относительный порог устраняет эту ошибку;
абсолютный критерий остаётся доступен через явный `epsilon`.
По теореме Вейля погрешность собственных чисел не превосходит ‖offdiag‖, то есть
при пороге по умолчанию — порядка `machine_eps · ‖A‖F`.

Порог `epsilon` — не относительная точность собственных чисел и не гарантированная
погрешность каждого из них. Даже после обнуления всех элементов сохраняются ошибки
округления float64. При успешном выходе дополнительно проверяются
`||B₀V − V diag(λ/scale)||F` и `||VᵀV − I||F` с допуском округления
`128 * machine_epsilon * n` (для невязки он умножается на `max(1, ||B₀||F)`
и складывается с финальной внедиагональной нормой).

Один поворот требует O(n) операций, полный проход — O(n^3), память — O(n^2).
Готовые `eig`/`eigh` не используются в решателе; NumPy предоставляет массивы и
линейную алгебру для проверок. `eigvalsh` вызывается только в тестах и ноутбуке как эталон.

### Предусловия и постусловия

Предусловия реализованы явными проверками с исключениями, постусловия — проверками конечности, невязки и ортогональности. Они работают и при запуске Python с `-O`, в отличие от `assert`.

| Исключение | Причина |
|---|---|
| `InvalidInputError` | Неверная форма, тип, симметрия, нечисловые/бесконечные значения или параметры |
| `ConvergenceError` | Исчерпан лимит проходов либо обнаружена стагнация |
| `NumericalError` | Переполнение, потеря ненулевого элемента при масштабировании, недостижимый масштаб порога, нарушение численных постусловий |

Все перечисленные ошибки наследуют `JacobiError`. Для конечных корректных входных
массивов алгоритм ограничен числом проходов: возвращает результат либо предусмотренную
ошибку. Произвольная точность и произвольный диапазон вещественных чисел не обещаются:
используется float64. Исчерпание памяти, ошибки ОС и пользовательские прерывания не
маскируются под ошибки алгоритма.

### Проверки

В `tests/test_solver.py` — 25 тестовых методов, включая 20 случайных симметричных
матриц размеров 2, 3, 5, 10 и 20 с фиксированным seed=42 и 15 матриц размеров 4–40
с масштабами от 10⁻²⁰⁰ до 10²⁰⁰.
Проверяются аналитические ответы, нулевая и диагональная матрицы, повторяющиеся
собственные числа, неопределённая матрица, матрица Гильберта, масштабы 10^±150,
неизменность входа, лимит проходов, ошибочные входы и численные пределы.
